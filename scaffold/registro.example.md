# Registro dei template

I punti di partenza per un nuovo progetto. Una riga per template. `scripts/verify` controlla la tabella.

- **Tipo:** `frontend`, `backend`, `fullstack` o `altro`.
- **Profilo:** `personal` o `lavoro`.
- **Origine:** `gh:proprietario/repo` per un repo GitHub marcato come template, `locale:percorso` per un progetto già fatto usato come riferimento. Per il profilo `lavoro` solo `locale:`, senza indirizzi o nomi di aziende.
- **Aggiornato:** data dell'ultima revisione del template (AAAA-MM-GG).
